## Downloading assets

If the filename is GLB, you can download it separately or whole .zip archive.

Otherwise (some of my assets (Site-19 and legacy assets), Class-D and unfixed guard from SCP: SL, non-ready or non-GLTF assets from SCP: Unity need full download)

## Using it
### Godot Engine
If your asset is .GLB ot .BLEND, then you need to convert this into GLTF for better file size before importing into Godot!
If your asset is .GLTF, nothing should be done.

## Regarding SCP-Containment Breach rooms

For SCP-Containment Breach rooms, switch to `asset-lib-v1` branch and check the git history (click on Commits button if you are using web interface) and download the archive from 28 November 2024
(if you want **only** my modifications, you can pick last `asset-lib-v1` state), **but it is not recommended**, because
I removed them, because of possible licensing issues (I don't know about rooms and textures, but for example, SCP-1499 model is from FPS Creator,
which may violate the CC-BY-SA 3.0 license, as stated both in SCP-Containment Breach and SCP Foundation wiki)

## Regarding SCP: Secret Laboratory unofficial assets (which had only old HCZ rooms):

For SCP: Secret Laboratory pre-14.0 rooms, switch to `asset-lib-v1` branch and check the git history (click on Commits button if you are using web interface) and download the archive from 25 July 2025 **or** you can download modified SCP:SL rooms from Taj Mod, [see dedicated README for that at `asset-lib-v2`](./GFX/By_Pop_Pop_Icard/README.md), **but it is not recommended**, because they:
1. Are not official, but extracted from the game.
2. Their CC-BY-SA license *may* or *may not* apply on it (it states *majority of the assets* are licensed under CC-BY-SA, but don't specify what assets are not licensed) -> resulting in possible licensing issues (see SCP:SL EULA).

> If you are Northwood Studios employee, and you see this, please, file the issue about SCP: Secret Laboratory asset usage, and I will restore removed rooms.
