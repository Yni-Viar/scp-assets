## Downloading assets

If the filename is GLB, you can download it separately or whole .zip archive.

Otherwise (some of my assets (Site-19 and legacy assets), Class-D and unfixed guard from SCP: SL, SCP-914, non-ready or non-GLTF assets from SCP: Unity) it is necessary to download the whole archive.

**⚠️ It is not recommended to use `git clone` for this repo because of bandwidth usage, please, use `Code -> Download ZIP`!**

## Using it
### Godot Engine
If your asset is .GLB ot .BLEND, then you need to convert this into GLTF for better file size before importing into Godot!
If your asset is .GLTF, nothing should be done.
