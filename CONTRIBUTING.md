# Contributing
## General rules

- If you want to contribute assets to the archive, please, read these rules:
    1. You may NOT steal proprietary assets, you may only add CC-BY-SA \ CC-BY \ CC0 licensed asset.
    2. The asset must NOT contain all kind of malware, tokens, passwords, api keys and obfuscated data.
    3. The asset may NOT contain disturbing and unlawful elements.

## Naming conventions
### .GLB 3D models
- Procedurally generated rooms should be named as `zone_type_roomname`
    - `type` can be:
        - `roomX` - generic room
        - `contX` - containment chamber, Class-D chamber, nuke chamber, e.t.c something important to contain
        - `ckpt2` - checkpoint
        - you can suggest another room type in Issues.
- Static rooms should be named as `type_roomname`:
    - unlike procedurally generated rooms, type can be anything, such as pd (Pocked Dimension), subl (Sublevel), sz (Surface Zone), e.t.c
- Other 3D models should be named under PascalCase
### Other assets don't have any conventions
